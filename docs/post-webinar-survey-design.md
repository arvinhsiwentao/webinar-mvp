# 看完直播問卷設計（Post-Webinar Survey）

> **目的**：發送對象為「看完 simulive 直播但還沒購買」的學員，目標是同時收集**商業模式驗證訊號**和**轉換率優化線索**，並對買家做動機歸因。
>
> **發送機制**：
> - **直播完整簡報 PDF 跟 post-webinar email 一起寄出**（用戶不需要填問卷就能拿到，當作直播後的標準回饋）
> - **填完問卷的真正誘因 = 《2026 年資本流向與普通人的投資戰略》Mike 語音直播精華（完整版）** — 這是 Mike 私下整理的深度分析，市面上沒有公開
> - 區隔設計：簡報 PDF 是「禮貌答謝」，戰略精華是「**真正讓用戶願意花 2 分鐘填問卷**」的鉤子

---

## 1. 設計背景

### 1.1 Funnel 現況（4/1 ~ 5/3 數據）

| 階段 | 人數 | 階段轉換率 | 健康度 |
|------|------|-----------|--------|
| 到站 | 6,372 | — | — |
| 點擊報名 | 759 | 11.91% | 🟡 偏低 |
| 完成報名 | 180 | 23.71% | 🔴 表單嚴重棄填 |
| 進入直播 | 144 | 80.00% | 🟢 健康（simulive 可隨時看，數字虛高合理） |
| 進入購買頁 | 71 | 49.31% | 🟢 內容有打動人 |
| **完成購買** | **5** | **🚨 7.04%** | 🔴🔴 **最痛瓶頸** |
| 整體 CVR | 5/6,372 | 0.078% | — |

### 1.2 問卷的目標客戶與 N

- **主要目標**：看完直播但沒買的人 ≈ **139 人/月**（144 進直播 - 5 購買）
- **次要目標**：已購買者 ≈ 5 人/月（學動機）
- **預期填答率**：30-40%（PDF 誘因撐得住）→ **每月 N ≈ 30-50 份**
- **設計含義**：N 偏小 → 開放題前面**先給結構化選項**才能看出分布；題數最多 8 題（含跳題），實填 ≤ 6 題

### 1.3 設計核心哲學

| 維度 | 我們的選擇 | 為什麼 |
|------|-----------|--------|
| 用途 | **驗證商業模式假設** > 觸發自動化 | N 太小，學習價值 > 自動化效率 |
| 結構 | **結構化選項 + 開放補充** 並用 | 80% 的人選結構化 → 看分布；20% 寫補充 → 抓 outlier |
| 分流 | **買家 vs 非買家**完全不同題目 | 兩群人問同樣的問題會稀釋訊號 |
| 高分/低分 | **都要追問** | 低分告訴我們哪裡要砍，高分告訴我們哪裡要更多 |
| Action | 每題的彙總分布 → 下個月**改 funnel/內容/方案** | 不只是 retargeting trigger |

## 2. 整份問卷邏輯流程

```
Q0. 看直播前對 Mike 的認識程度？  ← 對照組變數，所有後續題都要 cross-tab

Q1.   整體收穫評分 (1-4 ★，4 級無中間)
Q1-A. 哪一段最有啟發？           ← 所有人都答
Q1-B. 哪裡覺得不夠好？           ← 所有人都答

Q2-pre.  看直播前對「美股投資框架」的信心 (1-5)
Q2-post. 看完直播後同樣這件事 (1-5)
         delta = post − pre
 ├── delta ≥ +2 → Q2-高（哪些部分最有幫助）
 ├── delta = +1 → 跳過追問
 └── delta ≤ 0  → Q2-低（哪些部分還不夠 / 沒幫上）

Q3. 還想多了解什麼？（多選）

Q4. 你目前的狀態？  ← 分流題
 ├── A. 已購買 → Q5（為何而買）→ 結束
 ├── B/C. 還沒買 → Q6（為何不買）+ Q7（缺什麼）→ 結束
 └── D. 不打算買 → 結束（仍送 PDF）
```

## 3. 題目逐題拆解

### Q0. 看直播前你對 Mike 的認識？（**對照組變數**）

> **題目**：「看直播前，你对 Mike 老师的熟悉程度是？」
>
> **形式**：單選

#### 題目假設

> **核心假設**：直播觀眾是一個**冷暖流量混合的池子**，沒區分開的話，Q2（信任）和 Q5（買家動機）的數據會被嚴重污染。
>
> - 已認識 Mike 的暖流量本來就有預先存在的信任 → 拉高 Q2 平均分 → 誤判「simulive 模式建立信任有效」
> - 暖流量的購買動機是 IP 信任 → 拉高 Q5「Mike 個人風格」票數 → 誤判「整個 funnel 該重押 Mike IP」
>
> 這題是讓 Q2 / Q5 變得**可解讀**的對照組。沒它，後面所有商業模式假設驗證都打折。

#### 為什麼問這題

- **Q2 的 simulive 體溫計（delta = post − pre）**只在「冷流量子集」上才有意義 — 暖流量 pre 分本來就高，看 delta 才公平
- **Q5 的策略級洞察**要區分「IP 信任先存在」 vs 「simulive 建立 IP 信任」 — 兩者的下一步行動完全不同
- 獨立洞察：直播觀眾的冷/暖比例本身就是**廣告 / IP 經營策略的決策依據**
- 放最前面當 warm-up，**不會被 Q1/Q2 的內容/信任問題 anchor**

#### 選項假設

| 選項 | 流量類型 | 用戶心理 | 揭露訊號 |
|------|---------|---------|---------|
| A. 完全不认识，今天第一次接触 | 純冷流量 | 對 Mike 0 認知，全憑直播 60 分鐘判斷 | **真正的 simulive 轉換樣本** |
| B. 略有耳闻 / 看过一两次 Mike 的内容 | 微暖流量 | 廣告 / SEO / 推薦動態觸及過 | 廣告觸及深度的指標 |
| C. 关注 Mike 一段时间（YT / IG / podcast） | 暖流量 | 已對 Mike 有預設好感 | IP 經營的成果 |
| D. 老学员 / 朋友推荐 | 熱流量（轉介紹） | 受信任他人背書 | 口碑 / referral 機制的價值 |

#### 整題行動（**這題本身的 4 個獨立洞察**）

1. **A 比例**（冷流量佔比）→ 越高代表廣告投放規模越大、越需要關注 simulive 對冷流量的轉換力
2. **C+D 比例**（暖+熱）→ 越高代表 Mike IP / 推薦機制是當前主要流量來源，要持續投資
3. **D 單獨比例 > 10%** → 推薦獎勵機制 ROI 證明，可考慮正式設計學員推薦計畫
4. **A 比例 < 30%** → 廣告投放沒在開拓新流量池，光吃既有粉絲，會碰到天花板

#### 整題行動（**作為 Q2 / Q5 的對照組**）

- 所有 Q2 / Q5 的解讀都要**先按 Q0 切群**再看分布
- 詳細 cross-tab 邏輯見 Q2 / Q5 的「整題行動」段落

### Q1. 整體內容評分

> **題目**：「看完 Mike 老师的直播，你整体的收获感受是？」
>
> **形式**：**4 級量表（強迫選擇，無中間）**單選

#### 題目假設

> 假設：simulive 影片是**整個漏斗最大的內容飛輪**——同一份內容會被未來幾百上千人看到。如果分數低，**不是優化 landing page 或結帳頁的問題，是要重錄/重剪影片**。這題決定的是「要不要動最上游的內容資產」。

#### 為什麼問這題

- simulive 的特性：**單一影片承載所有未來流量**，內容好壞的槓桿是 100x landing page 改動
- 沒這題我們會**誤把內容問題當行銷問題**，一直在改下游而不知道源頭就有缺陷
- 這題也用來分流出「不喜歡內容」的雜訊（避免污染 Q2-Q7 的解讀）

#### 為什麼用 4 級量表（不用 5 級）

> **避免中央趨勢偏誤（central tendency bias）**：5 級量表的中間「3 / 普通」是人類逃避真實表態的避風港，多數人會選中間 → 數據被「不痛不癢」的雜訊填滿，看不出真正的好評/差評分布。**4 級無中間 → 強迫每個用戶選擇偏正面或偏負面**，每個選項都有實際語意。

#### 選項假設

| 選項 | 用戶心理 | 揭露訊號 | 後續處理 |
|------|---------|---------|---------|
| ⭐ 几乎没收获 | 完全不對盤 / 期待落差 | 內容方向錯誤 or 流量錯人 | 標記 `low_intent`，停止 retargeting |
| ⭐⭐ 收获不多 | 弱負面 | 內容無記憶點、缺乏 wow moment | 仍進 Q1-A / Q1-B 追問 |
| ⭐⭐⭐ 还算有收获 | 弱正面 | 有收穫但不夠強 | 仍進 Q1-A / Q1-B 追問 |
| ⭐⭐⭐⭐ 收获非常多，超出预期 | 強正面 | 內容極有效 | 進 Q1-A / Q1-B + 標記 super fan |

#### 整題行動

- **平均分 < 2.5**（即多數選 1-2）→ 排程 simulive 重錄/重剪
- **平均分 2.5-3.0** → 看 Q1-B 分布做局部剪輯
- **平均分 > 3.0** → 內容沒問題，重點看下游瓶頸
- **無論分數高低，所有人都進 Q1-A + Q1-B** → 兩面向資料完整收集

### Q1-A. 「哪一段对你最有启发？」（**所有人都答**）

> **形式**：多選（最多 3 個）

#### 題目假設

> 假設：「**好評最集中的段落 = 內容資產的鑽石**」。這一段該被剪短當廣告素材、放 landing page hero 區、變成 YT shorts 引流。**不問就不知道哪段最戳人**。
>
> **為什麼所有人都答（不只高分）**：即使整體只給 2 ⭐ 的低分用戶，也可能某幾段特別有啟發；強迫所有人回答能拿到**最完整的段落表現分布**。這對 simulive 重剪決策更精準。

#### 選項假設

> **選項對應實際直播片段**：所有選項對應 V7 逐字稿的**片段 01-34**（pre-sale 教學內容），片段 35 之後為銷售段，不放入問卷。

| 選項 | 對應片段 | 內容主題 | 用戶心理訊號 | 高選率策略意涵 |
|------|---------|---------|------------|---------------|
| A. 「为什么现在必须投资」与三大趋势 | 01-04 | 投資的必要性 / 財富重新分配 | 焦慮型驅動（怕被通膨 / 政策落下） | 拍類似 macro view 內容當廣告 hook |
| B. AI 产业链与六层架构分析 | 05-08 | AI 結構性投資 | 想抓未來主流產業 | 加強科技 / AI 主題系列內容 |
| C. 川普 2.0 政策红利（能源 / 国防 / 金融 / 制造业）+ 比特币 ETF + 降息周期 | 09-15 | 總體經濟機會點 | 想抓「對的時間做對的事」 | 跟著總經事件出 timely content（FOMC、財報季） |
| D. Mike 从负债 50 万到建立投资框架的个人故事 | 17-22 | 人物 IP / 蛻變敘事 | Mike 個人魅力驅動 | **整個品牌策略重押 Mike IP**（YT、IG、podcast） |
| E. 四类 ETF 配置框架（成长 / 防御 / 收益 / 进阶） | 23-25 | 系統化資產配置 | 想要系統而不是訊號 | 加強系統化框架類內容（不是個股推薦） |
| F. 用退休目标倒推资产配比的逻辑 | 26-28 | 量化決策框架 | 想要量化、可複製的決策方法 | 出財務目標規劃工具 / 計算機 |
| G. 卖期权收保费的策略（Sell Put / Sell Call） | 29-32 | 被動收入策略 | 想要現金流 / 「邊存邊賺」 | 拍期權主題系列內容（這群是 APP 高黏性客群） |
| H. 动态再平衡 + 长短线账户策略 | 33-34 | 長期可持續操作 | 想要不用每天盯盤 | 強調「低時間投入」內容（呼應 Q6 的「沒時間」阻力） |
| I. 没有特别有启发的段落 | — | 內容整體弱 | 全方位疲軟 | 跟 Q1 低分交叉驗證，內容方向全面重新規劃 |
| J. 其他___ | — | 開放 | 抓盲點 | 人工分析 |

#### 整題行動

- **Top 1 段落** → 剪 60 秒短影音當付費廣告 hook（直接拿 V7 該片段重剪）
- **Top 3 加總** → 構成下次 simulive 的內容權重重新分配
- **如果 D（Mike 個人故事）意外高** → 整個品牌策略重押 Mike IP，而非課程內容
- **如果 G（期權）特別高** → 期權課程是真正的成長點，行銷預算可向期權方案傾斜
- **如果 A（投資必要性）+ I（沒啟發）都高** → 內容偏「動機說服」但缺「實戰價值」，下次 simulive 要削減開場焦慮、增加實戰段
- **如果 H（動態再平衡）高 + Q6 D（沒時間）也高** → 「低時間投入」是用戶核心痛點，所有素材都該強調「每週 1 次操作就夠」

### Q1-B. 「哪里让你觉得不够好？」（**所有人都答**）

> **形式**：多選

#### 題目假設

> 假設：每個用戶（不論高低分）都可能對某些段落有保留意見。**強迫所有人回答 → 拿到內容缺陷的完整地圖**。高分用戶的「美中不足」回饋特別寶貴，因為這群人最理解內容、批評最精準。

#### 選項假設

| 選項 | 訊號 | 對應修正動作 |
|------|------|-----------|
| A. 内容深度不足，觉得太基础 | 流量質量太進階 / 內容定位錯誤 | 補充進階內容段或調整廣告 targeting |
| B. 讲解节奏太快 / 太慢 | pacing 問題 | 重剪節奏 |
| C. 案例不够有说服力 | 缺乏實證 | 補拍學員真實案例 / Mike 操盤紀錄影片 |
| D. 跟我的需求不相关 | TA 錯位（流量錯人 or 定位模糊） | 檢查 ad targeting / landing page 文案 |
| E. 内容偏理论，缺实际操作 demo | 缺實戰 | 補拍實際操作畫面段 |
| F. 没有让我觉得明显不够的地方 | 內容完整度高 | 正面訊號 |
| G. 其他___ | 開放 | 人工分析 |

> ⚠️ **不放「直播感太弱 / 像在看錄影」這種選項**：會直接破壞「這是真實直播」的核心幻覺，反而暗示用戶去懷疑。要驗證 simulive 模式可信度，靠 Q2 的信任分數和 Q2-低的「沒看到 Mike 操盤成果」分布間接推論即可。

#### 整題行動

- **選 A+D 高** → 流量品質問題，回頭看 ad source 和 landing page 文案
- **選 B+C+E** → 純內容剪輯 / 補拍工作
- **選 F 高** → 內容完整度沒問題，瓶頸不在內容
- **選 G 開放回答** → 每月人工讀，找新主題

### Q2-pre + Q2-post. 框架信心 pre/post 對照（**核心商業模式驗證**）

> **設計：兩題配對，計算 delta = post − pre**
>
> 改用 pre/post 對照而不是直接問「對 Mike 的信任度」的理由：
> - **直接問信任**有社交壓力，用戶傾向給客套分數
> - **delta** 才能分辨「直播的真正貢獻」vs「本來就有的信任」
> - 改問「對美股投資框架的信心」是**客觀對象**，無社交負擔
> - 用戶買的不是「我相信 Mike」，而是「**我相信用 Mike 教的方法可以做到**」— 後者才是真正驅動付費的信念狀態

#### Q2-pre

> **題目**：「在看这场直播**之前**，你对自己能掌握『美股投资框架 / 资产配置』的信心程度是？」
>
> **形式**：1-5 單選

#### Q2-post

> **題目**：「看完这场直播**之后**，同样这件事 — 你的信心程度是？」
>
> **形式**：1-5 單選

#### Q2-pre 選項

| 分數 | Q2-pre 描述（用戶看到的選項文案） |
|------|----------------------------------|
| 1 | 完全没概念 / 没信心 |
| 2 | 听过一些，但很模糊 |
| 3 | 知道大方向，但不清楚具体怎么做 |
| 4 | 比较清楚框架，还在摸索 |
| 5 | 已经有自己的一套，很有信心 |

#### Q2-post 選項

| 分數 | Q2-post 描述（用戶看到的選項文案） |
|------|------------------------------------|
| 1 | 还是没什么把握 |
| 2 | 大概听懂了，但还要再消化 |
| 3 | 知道方向了，还需要更多细节才能上手 |
| 4 | 比较有把握了，觉得可以开始试看看 |
| 5 | 完全清楚，准备马上套用 |

> **設計說明**：兩題的 1-5 是**相同等級的信心強度**（1 = 最低、5 = 最高），但措辭針對 pre / post 的時間點各自調整 — 看直播前的「沒概念」對應看完後的「還是沒把握」，看前的「已經有一套」對應看後的「準備馬上套用」。**delta = post − pre** 仍然有效，因為兩個量表的 anchor（最低、最高）對齊了。

#### 題目假設

> **核心假設**：simulive（預錄影片）能否在 60 分鐘內，**讓用戶從不懂框架→懂框架**？這個 delta = simulive 為商業模式創造的真實價值。
>
> 如果 delta 普遍很小（≤ +1），simulive 沒在做它真正該做的事 — 整個 funnel 上游可能要動（加真人 Q&A、加多場直播、改商業模式）。

#### 為什麼問這題（pre/post 比起單一信任分數的優勢）

1. **間接測信任，避免社交壓力**：用戶評價自己對框架的掌握度，不是評價 Mike 這個人
2. **delta 隔離 simulive 的真正貢獻**：暖流量 pre 分本來就高，看 delta 才公平
3. **更接近購買決策**：用戶「相信框架可行」 = 真實付費信念狀態
4. **長期趨勢可比較**：每個月平均 delta 變化 = simulive 內容版本迭代的效果體溫計

#### Delta 解讀

| Delta | 解讀 | 跳轉邏輯 |
|-------|------|---------|
| **+2 ~ +4** | 直播大幅提升信心 ✅ simulive 真的在做事 | → Q2-高（追問哪些部分最有幫助） |
| **+1** | 輕度提升 | 跳過 Q2-高/Q2-低，直接 Q3（避免題數膨脹） |
| **0** | 沒變化 | → Q2-低（追問哪裡還不夠） |
| **-1 ~ -4** | 🚨 **負向（極罕見但極重要）** | → Q2-低 + 標記 `simulive_negative_impact` 緊急排查具體段落 |

#### 整題行動

> 🚨 **必須先按 Q0 切群再看 delta，整體平均沒意義**

- **看 Q0=A（純冷流量）的子集 delta 平均**（這才是真正的 simulive 體溫計）
  - delta < +1 → simulive 對冷流量無認知提升效果，要動（加真人 Q&A、改商業模式）
  - delta +1 ~ +2 → 對冷流量「合格」，funnel 上游補社會證明
  - delta ≥ +2 → simulive 對冷流量有效 ✅，**是商業模式關鍵驗證成功**
- **若 Q0=A 子集 delta 低，但 Q0=C/D 子集 delta 高** → 模式對冷流量無效，但 IP / 推薦渠道很強 → 策略**改為深耕暖流量**而不是花錢硬推 simulive 給冷流量
- **Q2-pre 高 + delta 小** = 「本來就懂的人」，simulive 沒提供新東西 → 考慮做進階版內容
- **Q2-pre 低 + delta 大** = simulive 對**初學者最有效**，廣告 targeting 應該瞄準新手
- **delta 與 Q4（是否購買）相關性** = 驗證「框架信心」是否真的驅動購買，如果不相關 → 瓶頸不在信任，回頭看 Q6 的價格 / 支付摩擦
- **若出現負 delta** → 立刻交叉看 Q1-B（哪裡不夠好），找出哪段內容讓人「越聽越不信」，那段優先重剪/重錄

### Q5. 已購買 — 為什麼決定買？（Q4 = A 顯示）

> **題目**：「最后让你按下『立即购买』的关键原因是？（最多 2 个）」
>
> **形式**：多選 + 開放追問

#### 題目假設

> **核心假設**：我們**不知道**真正驅動成交的因子是「**內容專業度（產品力）**」還是「**Mike 個人魅力（IP 力）**」還是「**價格訊號（行銷力）**」。
>
> 答案不同，**整個品牌與行銷策略要往不同方向走**：
> - 產品力驅動 → 重壓「內容深度 demo」、課綱拆解
> - IP 力驅動 → 重壓 Mike 個人 YT/IG/真人露出
> - 行銷力驅動 → 重壓限時優惠、階梯定價
>
> 這是**最大的策略級洞察題**，沒問就是猜。

#### 選項假設

| 選項 | 驅動類型 | 高選率對應的策略方向 |
|------|---------|------------------|
| A. 内容专业度说服我 | 產品力 | 加強內容 demo、操盤紀錄敘事、課綱拆解 |
| B. Mike 的个人风格让我觉得可信 | IP 力 | 重壓 Mike 個人品牌、YT/IG、真人露出 |
| C. 学员见证 / 真实成果 | 社會證明力 | 拍學員訪談影片、強化案例敘事區塊 |
| D. 想试试看这套方法（尝试心态） | 嘗鮮型 | 加 30 天退費保證放大這群人 |
| E. 价格 / 限时优惠刚好打中 | 行銷力（價格驅動） | 加強限時 / 階梯定價 |
| F. 朋友推荐 | 口碑驅動 | 設計推薦獎勵 / 共學優惠 |
| G. 其他___ | 開放 | 抓盲點 |

#### 追問題：「购买前最后一个让你犹豫 5 秒的点是什么？」

- **形式**：開放輸入（選填）
- **假設**：即使最終買了，臨門一腳仍有微小猶豫——這個猶豫**正在阻擋其他類似用戶**
- **行動**：每月人工讀，找出共通主題 → 結帳頁加對應的 reassurance copy（「擔心 X？我們提供 Y」）

#### 整題行動

> 🚨 **必須先按 Q0 切群再看分布，否則策略方向會誤判**

- **N 雖小（5/月）** 但長期累積 6 個月就有 30 份買家樣本，足以做策略決策
- **重要 cross-tab**：
  - **Q0=A（冷流量）買家的 Top 動機** → 這是 simulive 真正的成交驅動因子
    - 冷流量買家若 Top = B（Mike 個人風格）→ **simulive 真的能在 60 分鐘建立可購買的 IP 信任** ✅ 模式核心驗證成功
    - 冷流量買家若 Top = A+C（內容/見證）→ 產品力與社會證明驅動，Mike IP 不是必要條件
  - **Q0=C/D（暖+熱）買家的 Top 動機** → 預先存在的 IP 信任驅動，不能算 simulive 的功勞
    - 若這群買家佔大多數且 Top = B → **真正該做的是繼續經營 Mike IP / 推薦機制**，不是 simulive funnel 改造
- **若全體 Top 1 是 B 但拆 Q0 後發現 80% 來自 C/D** → 不要重押 funnel 內 Mike 形象，要重押**上游 IP 經營**（YT / IG / podcast）
- **若全體 Top 1 是 A+C** → 強化內容力 + 社會證明（不分 Q0 都成立）
- **若 E（價格）高** → 行銷力驅動，可考慮全年都有限時活動

### Q6. 沒買 — 主要原因？（Q4 = B 或 C 顯示）

> **題目**：「目前还没下单，最主要的原因是？」
>
> **形式**：**單選**（逼用戶選最痛的那個）

#### 題目假設

> 假設：阻力類型有限（業界研究顯示主要是 6-7 種），**單選**比多選更有訊號——強迫用戶在多個阻力中選最關鍵的那個，避免「全選」失去判讀價值。

#### 為什麼問這題

- 結帳頁 7% 轉換率（71→5）的瓶頸**就在這題**
- 沒這題我們是在猜，可能花一個月優化價格但真實瓶頸是支付摩擦

#### 選項假設

| 選項 | 阻力類型 | 對應解法 |
|------|---------|---------|

| D. 担心没时间好好上完课 / 跟操作 | 時間成本懷疑 | 強調「每週 1 次操作 + APP 訊號通知」的低門檻 |

| H. 还想看更多 Mike 的口碑 / 学员实际成果 | Trust deficit（外部證據） | 學員見證影片合輯 + Mike 媒體報導 |
| I. 对 Mike 老师的信任感还不够 | Trust deficit（個人信任） | 寄 Mike 個人故事長文 + 過去操盤紀錄 |

- **若 E 高** → 馬上做「方案推薦 quiz」工具
- **若 H + I 加總 > 30%（信任類）** → 跟 Q2 低分子集交叉看，集中補社會證明 + Mike 個人 IP 內容

## 4. 設計細節決策記錄

### 4.1 Q1 / Q2 為什麼採不同追問策略

**決策**：
- **Q1（內容）**：所有人都答 Q1-A（哪段最好）+ Q1-B（哪裡不夠好）兩題，**不分高低分**
- **Q2（信任）**：高低分追問**互斥**（高分問為什麼信任、低分問為什麼還無法信任）

**Q1 為何兩題都問**：
- 即使整體只給 1-2 ⭐ 的低分用戶，也可能某幾段特別有啟發；即使給 4 ⭐ 高分的用戶，也可能某幾段不夠好
- **強迫所有人回答兩面 → 拿到段落表現的完整地圖**，對 simulive 重剪決策最精準
- 高分用戶的「美中不足」回饋特別寶貴（最理解內容、批評最精準）

**Q2 為何條件互斥**：
- 信任度是「整體感覺」，不像內容是「段落組合」 — 沒有「某段建立信任、某段破壞信任」這種拆解
- 4-5 分用戶的「哪裡不信任」答不出來（強答只會得到雜訊）
- 1-3 分用戶的「為什麼信任」也答不出來
- 互斥分流可以讓兩個追問題的選項各自針對性更強

### 4.2 為什麼 Q4 把「不打算買」的人也送 PDF

**決策**：D 選項（不打算買）的人**仍送 PDF**

**理由**：
- 送 PDF 的成本接近 0（GCS storage 費用 negligible）
- D 群的回答仍然有資料價值（驗證 Q1-Q3）
- 不送 PDF 會讓 D 群在 Q4 騙選 B/C（污染分流數據）
- 給 D 群正向體驗，**未來可能變成 referral source**

### 4.3 為什麼 Q5 限「最多 2 個」而不是 3-5 個

**決策**：Q5（買家動機）強制限選 2 個

**理由**：
- 買家會有「全部都重要」的後見之明偏誤

- 我們需要的是 priority signal，不是 list

### 4.4 為什麼 Q6 是單選，Q7 是多選

**決策**：Q6 單選、Q7 多選

**理由**：
- Q6（阻力）：阻力通常有一個是壓垮駱駝的最後稻草，**單選逼出最痛點**
- Q7（誘因）：誘因可以疊加（更多見證 + 退費保證 + 比較表），**多選反映真實心理**

### 4.5 誘因設計（雙層獎勵結構）

**決策**：採雙層獎勵設計
- **第一層（無條件）**：直播完整簡報 PDF — 跟 post-webinar email 一起寄出，所有觀看者都拿得到，**填不填問卷都有**

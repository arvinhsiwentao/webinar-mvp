# On-Demand 漏斗 + 信任養成規劃書

> 狀態：**待老闆確認** | 建立日期：2026-04-22

---

## 1. 關鍵問題：用戶高度投入後為何仍不買？

排除法：
- ❌ 不是沒興趣 — 看完就是有興趣
- ❌ 不是價格 — $79 已經很低
- ❌ 不是風險 — 30 天退款保證

真正的原因是**信任不夠**，而信任的公式是：

> **信任 = 能力 × 一致性 × 時間 × 共鳴**

一場 36 分鐘的直播能證明「能力」，但完全無法證明「一致性」和「時間」。
金融教育領域充斥太多割韭菜的人，用戶的防禦機制很高，一次接觸無法突破。

### 用戶沒買時腦裡在想什麼

1. 「這個人講得不錯，但我不認識他」— 一次直播無法對抗過去被騙的經驗
2. 「我要先去查一下這個人」— 離開後 Google Mike、看 YouTube，然後就忘了回來
3. 「內容很好但我不確定我做得到」— 不是不信 Mike，是不信自己
4. 「我要跟另一半討論」— 投資決策通常不是一個人的事
5. 「不急，之後再說」— 沒有真正的 deadline，「之後」就是「永遠不」

### 信任建立的自然路徑

用戶對 KOL 的信任不是「聽完一場講座就能輕易建立的」，而是：

```
偶然發現 → 覺得有料 → 追蹤/訂閱 → 反覆看到 → 某天需要時想到他 → 購買
```

心理學上的 mere exposure effect（純粹曝光效應）— 看到越多次就越信任，
光是重複出現就夠了，不需要每次都給新資訊。

**現在的問題：用戶的信任旅程被壓縮成一次 36 分鐘。**
On-demand + 再行銷的目的就是把這條路徑展開成 1-2 週。

## 2. 信任建立的四大策略

### 策略一：讓學員替你說話（社會證明，最強）

用戶不信 Mike 自己說的，但信「跟我一樣的普通人」說的。

| 素材 | 怎麼用 | 放在哪裡 |
|---|---|---|
| 學員社群截圖 | LINE/Discord 真實對話，有人說「照做第一個月收了 $500 保費」 | EDM Day 3 + /watch 頁側欄 |
| 影片見證 | 3-5 個學員錄 30 秒短片，越真實越好，不要太專業 | /free landing + /watch 頁 |
| 學員數量 | 「已有 3,200+ 學員加入」— 數字本身就是信任 | 所有頁面 footer |
| 成果截圖 | 學員的帳戶收益截圖（脫敏） | EDM + /watch 頁 |

關鍵：**不要把見證集中在一個頁面，而是穿插在每個接觸點** — 每封 EDM 放一個不同的學員故事。

### 策略二：持續提供免費價值（純粹曝光效應）

信任來自「這個人一直在給我有用的東西，而且沒有要我付錢」。

- **每週時事分析信**：「本週 Fed 決議後 ETF 該怎麼配」— 讓用戶覺得光是 EDM 就值得訂閱
- **YouTube 短影片**：2-3 分鐘的美股觀點，用戶看了覺得有料 → Google Mike → 發現有課程
- **免費工具**：例如「ETF 配比計算器」— 輸入退休目標 → 輸出建議配比 → 底部帶課程 CTA
- **市場波動時主動發信**：大跌那天寄一封「Mike 怎麼看今天的跌幅」— 最有效的信任建立時機

重點：**這些內容不賣東西**。底部可以有小 CTA，但主體是純粹的價值。
用戶會想：「這個人免費都給這麼多，付費的一定更好。」

### 策略三：展示真實的人（不只是專業面）

KOL 信任不只是「這個人懂投資」，還有「這個人真實、不會騙我」。

- **展示失敗**：Mike 踩過的坑、虧過的錢 — 反而增加信任，因為「賣課的人通常只講自己多厲害」
- **日常面**：Mike 的日常工作流程、為什麼做這件事、背後的動機
- **互動**：回覆用戶留言、直播 Q&A — 「這個人是真的在乎學員，不只是賣完就跑」
- **透明度**：「我上個月的操作覆盤」— 贏的講、虧的也講

### 策略四：微承諾階梯（降低每一步門檻）

$79 雖然低，但「付費」這個動作本身就是心理門檻。
在付費之前，用戶需要先完成幾個免費的微承諾：

```
看直播（已完成）
    ↓
加入免費 WhatsApp/LINE 群 ← 門檻幾乎為零
    ↓
看到群裡學員的真實討論 ← 社會證明，自然發生
    ↓
收到幾封有價值的 EDM ← 一致性，反覆曝光
    ↓
某天市場波動，想到 Mike 說過的話 ← 自然觸發點
    ↓
購買 ← 信任已經建立，決策變得容易
```

每一步都是零成本、零風險的小動作，但累積起來就是信任。

## 3. 內容生態（不分漏斗，現在就能做）

以下策略**不依賴 on-demand 機制**，simulive 和 on-demand 都適用。
看完直播（不管哪種形式）後，用戶進入同一套內容養成系統。

### EDM Drip 序列

```
Day 0   報名 + 看直播
        ├─ 確認信：影片大綱整理 + 結帳連結
        └─ 邀請加入免費 WhatsApp 群

Day 1   價值提醒
        「Mike 在影片第 12 分鐘講的 ETF 配置框架，是整場最核心的」
        （on-demand 版可帶時間戳連結，simulive 版帶重點文字摘要）

Day 3   學員見證 #1
        真實學員故事 + 帳戶截圖
        「Lisa，護士，去年開始用 Sell Put，現在每月穩定收 $600 保費」

Day 5   免費時事分析
        「本週美股：科技股回調，Mike 怎麼看？」
        不賣東西。底部小字：想學系統化框架？這裡了解更多 →

Day 7   學員見證 #2 + 軟推
        不同學員的故事
        「現在加入，Mike 會在群裡回答你的第一個問題」

Day 10  Mike 的真實面
        「2022 年我在期權上虧了 $XX,XXX — 這就是為什麼我後來建立了風控 SOP」
        真實、有溫度、不賣東西

Day 14+ 每週一封時事信
        持續提供價值，維持曝光
        每封信底部固定帶結帳連結
        不設終止日 — 養到轉換或取消訂閱為止
```

### 行為觸發信（即時，不受時間線限制）

| 觸發條件 | 動作 |
|---|---|
| 用戶點了結帳但沒完成 | 1 小時後寄 abandoned cart 信 + 「有任何疑問？直接回信問我」 |
| 市場大幅波動（VIX > 25） | 即時寄「今天市場怎麼了？Mike 的看法 + 你可以怎麼做」 |
| 用戶加入 WhatsApp 群 | 自動私訊歡迎 + 引導看直播精華段落 |

### 長期內容生態

```
廣告/自然流量
    ↓
直播（Simulive 或 On-demand，建立第一印象）
    ↓
EDM + 免費群（反覆曝光，建立信任）
    ↓
時事分析信 / YouTube / 短影片（持續價值）
    ↓
購買課程或 APP（信任到位，自然轉換）
    ↓
學員社群（產生新的社會證明 → 回饋到漏斗上層）
```

最終目標：**不是每個人看完直播都要買，而是每個報名的人都進入 Mike 的內容圈。**
有些人一週就買，有些人一個月，有些人三個月 — 但只要還在圈裡，就有機會。

## 4. On-demand 機制（需要工程開發）

On-demand 解決的是內容生態無法解決的問題：**影片本身只看一次不夠。**

| | Simulive | On-demand |
|---|---|---|
| 內容生態（EDM、群、時事信） | ✅ 可以做 | ✅ 可以做 |
| 用戶重看影片 | ❌ 不行 | ✅ 可以 |
| 用戶自己選時間看 | ❌ 要配合場次 | ✅ 可以 |
| EDM 帶時間戳連結回某段落 | ❌ 做不到 | ✅ 可以 |
| 跟另一半一起再看一次 | ❌ 做不到 | ✅ 可以 |

### 建議優先順序

```
Phase 1（現在就做）：內容生態
  → EDM drip 序列 + WhatsApp 群邀請
  → 對現有 simulive 用戶馬上有效
  → 不需要工程開發，只需要 SendGrid 設定 + 內容準備

Phase 2（數據驗證後）：On-demand 影片頁
  → 等 Phase 1 跑出數據，確認「多次接觸 → 轉換」假設成立
  → 再投入工程做 /free landing + /watch 影片頁
```

### URL 結構

| 頁面 | Simulive | On-demand |

## 6. 風險與注意事項

1. **沒有緊迫感 = 無限拖延**：On-demand 的風險是用戶「收藏了但永遠不看」。EDM drip 序列是對抗這個的關鍵
2. **廣告素材要調整**：On-demand 的廣告不能用「限時直播」的切角，要改成「免費完整課程」之類的
3. **兩條漏斗的廣告預算分配**：建議初期 70% simulive / 30% on-demand，看數據再調整
4. **影片內容一致性**：如果影片裡有「今天直播限定」之類的口述，on-demand 觀眾會覺得奇怪
5. **內容生態需要持續產出**：時事信、短影片需要 Mike 定期產出內容，這是營運成本不是工程成本
